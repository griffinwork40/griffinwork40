# Hey, I'm Griffin

I build agent systems that actually ship -- local-first infrastructure for
running coding agents: orchestration, supervision, and the runtimes that
tie them together.

Went from line cook to founding [GRAIsol](https://graisol.com) in March 2025.
Since then: ~13,000 GitHub contributions across 100+ repos, an open-source
agent runtime with 1,000+ npm releases, and 12 published packages.

I don't out-type teams -- I build the tooling that lets one person ship at
team scale.

## What I'm building

| | |
|---|---|
| [agent-afk](https://github.com/griffinwork40/agent-afk) | Open-source TypeScript coding-agent runtime/harness. ~551K LOC, 1,000+ npm releases, Apache-2.0. |
